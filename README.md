# FAST Strength Systems — IT 195 E-Commerce

This repository contains Peter Fast's IT 195 e-commerce project: the FAST Strength Systems landing page and its supporting course context.

## Run locally

Open this repository in VS Code, open `index.html`, and select **Go Live**. The current site is a static HTML/CSS/JavaScript experience. Files under `backend/` are incomplete prototypes and are not required for the landing-page preview.

## Repository map

- `index.html` — landing-page structure and content
- `styles.css` — responsive visual design
- `script.js` — program finder, media controls, and page interactions
- `Images/`, `videos/`, `music/` — site media
- `backend/` — incomplete PHP prototype
- `docs/PROJECT_STATE.md` — current project status
- `docs/HANDOFF.md` — exact next action for the next session
- `docs/DECISIONS.md` — durable decisions and reasoning
- `docs/COURSE_REQUIREMENTS.md` — confirmed course requirements and evidence
- `docs/ASSIGNMENT_TRACKER.md` — deliverables and deadlines
- `docs/CHANGELOG.md` — course-project change summary
- `docs/DESIGN_CHANGELOG.md` — detailed design research and verification record
- `AGENTS.md` — repository-specific operating instructions

## Course boundary

This repository is for IT 195. IT 406 Capstone records must remain in the separate IT 406 context repository.
